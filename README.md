# CODEAM

Три самостоятельные React-композиции первого экрана:

- **01 · Масштаб** — светлая типографическая афиша с крупным фирменным написанием.
- **02 · Сигнал** — тёмная предметная сцена, металл и лаймовый акцент.
- **03 · Редакция** — редакционная типографика и интерактивные этапы работы.

В `/?concept=2` после исходного экрана последовательно расположены три дополнительных hero с той же металлической графикой:

- **02.A · Манифест** — крупный лаймовый заголовок, центральный логотип и отдельный блок навигации.
- **02.B · Ателье** — светлая редакционная половина, выразительный Manrope и высокий кадр с металлом.
- **02.C · Индекс** — боковая навигация, модульная композиция и крупное CODEAM снизу.

Прямые якоря: `/?concept=2#metal-manifest`, `/?concept=2#metal-studio`, `/?concept=2#metal-index`.

## Индекс: интро и настоящая 3D-сцена

`/` — главная страница с выбранной версией «Индекс», без панели сравнения. Старый адрес `/?concept=2/index` также поддерживается. Логотип в шапке пересобран по изображению пользователя: две диагонали и изогнутая четырёхлучевая звезда. В loader используется плоский силуэт в вытянутых пропорциях скульптуры: два одинаковых параллелограмма с общим наклоном и горизонтальными торцами, звезда с четырьмя симметричными лучами. Перспектива, фаски и боковые грани в силуэт не переносятся.

1. Диагонали входят по направлению своего наклона с разных сторон; затем появляется и останавливается вращающаяся звезда.
2. Вектор растворяется в объёмной модели. Чтобы сохранить качество исходной графики, её шлифовка, блики и освещение перенесены в материалы отдельных замкнутых плит и объёмной звезды. Это настоящая геометрия Three.js с привязанными к объектам UV; исходная картинка не используется как плоская карточка с логотипом. Диагонали поворачиваются за курсором примерно до ±3,5°; звезда дополнительно поворачивается вокруг собственного центра и слегка смещается. Освещение запечено для основного ракурса, свободный обзор со всех сторон не предусмотрен.
3. Один скролл, свайп вверх или кнопка продолжения запускают переход к hero. Один и тот же WebGL canvas остаётся смонтированным; меняется область рендеринга и положение модели, появляются элементы «Индекса». Вход завершается по сигналу от финального кадра сцены. Сетка перехода подготовлена до интро, место под полосу прокрутки зарезервировано: завершение docking не перестраивает область рендеринга.

Есть пропуск заставки, повтор, управление клавиатурой, поддержка reduced motion и векторный fallback при недоступном WebGL. Пропуск мгновенно размещает сцену в hero, сохраняя взаимодействие с курсором; reduced motion отключает это движение отдельно. После проявления модель медленно покачивается вокруг опоры у пола, а звезда слегка поворачивается отдельно. Это движение складывается с реакцией на курсор. Все материалы локальные. Three.js загружается только для этого адреса. Рендер приостанавливается вне активной секции, за пределами видимой области и при скрытой вкладке; reduced motion оставляет модель неподвижной.

В интро и hero зафиксирован **Исходный свет 01**. Переключатель удалён; старый параметр `light` больше не меняет основной экран. Сохранены исходные блики, шлифовка и отражения металлической сцены.

Файлы: `IndexExperience.tsx`, `index-experience.css`, `MatchedMetalScene.tsx`, `matchedMetalGeometry.ts`, `matchedLightingMaterial.ts`, `brandShape.ts`, `public/assets/brand-symbol.svg`.

Экспериментальная версия с полностью физическим освещением сохранена для сравнения: `/?concept=2/index&material=physical` (`MetalLogoScene.tsx`, `metalSceneGeometry.ts`). Основная версия использует исходную фактуру, поскольку она точнее сохраняет выбранную пользователем графику.

## Следующие секции: студия, работы и услуги

Заголовок hero: «Развиваем сайты, на которых бизнес получает заявки». После hero расположена светлая обзорная секция «Сайты, сервисы и продвижение». В ней четыре направления: веб-сайты, реклама в Яндексе, приложения, автоматизация. Ряд «Нам доверяют» содержит названия из предоставленного пользователем референса: Весна, Diamond, Щёкино, Сильвер, READY-FLY, SYNAPSE. Ссылка «Смотреть работы» ведёт к тёмной вертикальной ленте четырёх проектов из референса. В обзоре добавлены предложение первичного разбора, кнопка «Получить разбор сайта» и сценарии «Есть сайт» / «Сайта ещё нет». Форма разбора содержит адрес сайта и сохраняет локальный бриф; отправка на сервер не подключена. Блок доверия использует Unbounded. Превью работ пока схематичные, с подписью «Структура сайта». Секция входит в экран цельной композицией: первый кейс расположен на 24 px ниже заголовка и остаётся на месте ещё на протяжении 30 svh прокрутки после закрепления секции. Далее один жест колеса запускает полный переход к следующему или предыдущему кейсу за 1,3 с. Входящий жест останавливается на первом кейсе; инерционный хвост не пропускает работы. При touch и reduced motion сохраняется обычная лента. Первый кейс не использует раннюю View Timeline-анимацию; удержание реализовано нативным sticky-контейнером и симметрично работает при возврате. Закреплённая подпись плавно меняет название, описание, категорию и счётчик активного проекта; кнопка открывает его краткое описание. IntersectionObserver определяет активный кейс, CSS View Timeline отвечает за появление превью, а отдельный контроллер `useCaseWheelSteps.ts` задаёт остановки для колеса через общий Lenis. Заголовок проявляется по буквам, когда начало секции достигает середины экрана: 35 мс между буквами, мягкое появление в течение 1,4–1,7 с. Рассеянная подсветка фона меняет оттенок за 1,8 с через прозрачность готовых градиентных слоёв и медленно перемещается по 18-секундному циклу. Движение света приостанавливается вне активной секции и в скрытой вкладке. У проекта есть `ambient` и необязательная обложка `cover: { src, alt, position }`. После загрузки изображения его основной оттенок вычисляется один раз на копии 24×24; при недоступном чтении пикселей сохраняется заданный цвет. Размер изображения зарезервирован, ошибка загрузки возвращает схематичное превью. На низких экранах и при reduced motion проекты идут обычным потоком с собственными подписями. Следом идут подробные услуги с раскрывающимися строками; первая строка открыта при загрузке. «Далее» в hero ведёт к обзору, навигация «Работы» и «Услуги» — к соответствующим секциям; «Обсудить задачу» открывает существующий локальный бриф.

Компоненты и стили: `IndexOverview.tsx`, `IndexWorks.tsx`, `IndexServices.tsx`, `index-works.css`, `index-services.css`. WebGL canvas ограничен отдельной оболочкой hero и не увеличивается на высоту всей страницы. Интро блокирует доступ к следующим секциям до завершения.

### Переход из hero

Переход использует принцип VNE: цветная плоскость и содержимое двигаются независимо. Светлая секция раскрывается снизу и перекрывает неподвижную металлическую сцену. Текст hero только смещается вверх и исчезает; текст и графика не сжимаются по вертикали. Видимая область следующей секции раскрывается двумя встречными перемещениями внешнего контейнера и его содержимого, поэтому шрифты и строки сохраняют размер.

Колесо мыши управляет двумя отдельными шагами. Первый щелчок скрывает hero, поднимает крупную надпись CODEAM и меняет её цвет на чёрный на светлом фоне. Это самостоятельное остановленное состояние: содержимое обзора ещё скрыто. Второй щелчок пропорционально уменьшает надпись до места под символом и плавно проявляет новую секцию. Для начала обратной анимации нужны два отдельных жеста вверх у верхней границы обзора: первый оставляет экран на месте, второй в течение 2,6 секунды запускает возврат. Инерционный хвост одного жеста не подтверждает возврат (пауза между жестами — минимум 220 мс). Скролл вниз, навигация, клавиатура и touch сбрасывают подтверждение. При возврате из нижних секций первый пересекающий границу жест останавливается на обзоре. Далее обратный переход проходит те же две остановки.

`useIndexMorph.ts` связывает анимации с нативным `ViewTimeline`; обе половины используют `cubic-bezier(.59,0,.38,1)`. `indexWheelSteps.ts` запускает конечное перемещение прокрутки к соседней остановке по одному событию колеса и отсекает хвост того же жеста. Длина полного диапазона — 0,8 высоты экрана. После перехода секция читается обычной прокруткой; клавиатура и touch сохраняют обычное управление. Изменение высоты аккордеона не меняет длину перехода. Canvas сохраняется одним экземпляром, а взаимодействие с металлом приостанавливается на время перехода. При `prefers-reduced-motion` или отсутствии поддержки `ViewTimeline` секции идут обычным потоком, с готовой подписью под логотипом.

## Плавная прокрутка

На всём сайте используется Lenis 1.3.26 — версия и параметры из локального проекта VNE: `lerp: 0.1`, `smoothWheel: true`, `wheelMultiplier: 1`, `syncTouch: false`. Цикл кадров работает только во время движения. Интро, открытые диалоги и reduced motion отключают сглаживание; якоря, hero и кейсы согласованы через `src/scroll/pageScroll.ts`, чтобы несколько анимаций не управляли прокруткой одновременно.

## Структура

Во второй секции главной страницы `/` доступны четыре композиции: исходная, «Редакционный», «Манифест» и «От задачи». Переключение — стрелками по краям секции или клавишами ←/→ при фокусе внутри неё. По умолчанию открыт «Редакционный». Все варианты занимают общий измеряемый блок, чтобы переключение не сдвигало позицию прокрутки и секцию кейсов; неактивные варианты скрыты от фокуса и скринридера. Реализация — `IndexOverview.tsx` и `overview-variants.css`.

После кейсов сразу идут услуги, без промежуточной полосы «К услугам». В `IndexServices.tsx` три независимых варианта: «Тёмный список» (аккордеон), «Три направления» и «От задачи». Следом `IndexProcess.tsx` показывает пять этапов — от разбора до развития — в вариантах «Карта этапов», «Маршрут» и «Журнал проекта». Переключатели реализованы в `DesignVariants.tsx`: на компьютере высота каждой секции сохраняется, на мобильном используется естественная высота выбранной композиции. Кнопки открывают существующие демонстрационные формы проекта или разбора сайта.

`src/concepts/` — независимые варианты и их стили; `src/components/Shared.tsx` — шапка и общие элементы; `src/App.tsx` — просмотр, сравнение и демонстрационные диалоги.

После процесса идут блоки о студии, отзывов и заявки: по три независимые композиции со стрелками по краям. `IndexClosingSections.tsx` содержит студию и отзывы из предоставленного макета; вместо отсутствующего портрета используется фирменная заглушка. `IndexContact.tsx` сохраняет одну 3D-сцену и одну форму при переключении вариантов. Сцена занимает фон всей секции, модель позиционируется слева, форма имеет полупрозрачную подложку. Сцена загружается при приближении, при уходе за экран рендер приостанавливается; reduced motion отключает движение. Форма сохраняет бриф локально, отправка заявок на сервер не реализована.








## Публикация

```sh
npm ci
npm run build
npm start
```

Собранная версия доступна на `http://127.0.0.1:4173/`. Сервер отдаёт только содержимое `dist`, исходники и локальные файлы недоступны. `HOST` и `PORT` можно переопределить переменными окружения.

Для публичной ссылки через Cloudflare Quick Tunnel в отдельном процессе:

```sh
cloudflared tunnel --url http://127.0.0.1:4173 --no-autoupdate
```

Cloudflared напечатает HTTPS-адрес `*.trycloudflare.com`. Адрес временный и может измениться при перезапуске. Сервер и туннель должны продолжать работать; выключение компьютера отключает сайт. Для постоянного адреса нужен именованный туннель и домен в Cloudflare.

### GitHub Pages — основной публичный хостинг

Адрес: https://evgenii-barov.github.io/codeam/

Workflow `.github/workflows/pages.yml` автоматически устанавливает зависимости, выполняет `npm run build:pages` и публикует `dist` при каждом push в `main`. Для Pages используется base `/codeam/`; обычная команда `npm run build` и локальная разработка сохраняют корневой адрес `/`. Пути изображений и 3D-текстуры учитывают `import.meta.env.BASE_URL`.
